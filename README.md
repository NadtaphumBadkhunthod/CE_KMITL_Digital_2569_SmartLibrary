# Smart Library (ระบบห้องสมุดอัจฉริยะ)

โครงงานวิชา **01076113 Digital System Fundamentals in Practice** ภาคเรียนที่ 1/2569 คณะวิศวกรรมศาสตร์ สจล. (KMITL)

ระบบห้องสมุดจำลองที่ใช้บอร์ด FPGA **EDGE Spartan-7 (XC7S15-FTGB196) 2 บอร์ด** เป็นหน่วยประมวลผลหลัก
ตรรกะควบคุมทั้งหมดอยู่ใน FPGA ส่วน ESP8266 บนบอร์ดทำหน้าที่เป็นเว็บเซิร์ฟเวอร์ (หน้าจอผู้ใช้) และเก็บรายการหนังสือ

รายละเอียดที่มา วัตถุประสงค์ และขอบเขต อยู่ใน [docs/Proposal_SmartLibrary.pdf](docs/Proposal_SmartLibrary.pdf)

## ความสามารถ

| ระบบ | การทำงาน | อยู่ที่ |
|---|---|---|
| ไฟห้อง | โหมด Auto เปิด-ปิดตามความสว่างจาก LDR / โหมด Manual กดปุ่มบนบอร์ดหรือกดบนเว็บ / เลือกโหมดจากเว็บ | บอร์ด 1 |
| แอร์ | จำลองบน 7-segment เช่น `24.5C` ปรับทีละ 0.5 °C ทุก 2 วินาทีตามอุณหภูมิห้องจาก LM35 ในช่วง 16–27 °C | บอร์ด 1 |
| พัดลม | เปิด-ปิดด้วยปุ่มบนบอร์ดหรือจากเว็บ | บอร์ด 1 |
| เตือนควัน | MQ-2 แบ่งปลอดภัย/อันตราย อันตรายแล้ว buzzer ดัง และเว็บขึ้นแจ้งเตือนเต็มจอพร้อมเสียงไซเรนบนมือถือ | บอร์ด 1 + เว็บ |
| โต๊ะ | สวิตช์เลื่อน 3 ตัวแทนโต๊ะ 3 ตัว แสดงจำนวนที่นั่งว่าง/ไม่ว่างบน LCD 16×2 และการ์ดโต๊ะบนเว็บ | บอร์ด 1 + เว็บ |
| หาหนังสือ | ค้นหาบนเว็บ กด Follow แล้วบอร์ด 2 เปิดไฟโซนและไฟชั้นของหนังสือเล่มนั้น 7-segment แสดง `โซน-ชั้น` | เว็บ + บอร์ด 2 |

## โครงสร้างระบบ

```
มือถือ / คอม ──Wi-Fi──► ESP8266 (บนบอร์ด 1) ──UART──► FPGA บอร์ด 1 ──UART (สาย J5 C14)──► FPGA บอร์ด 2
  หน้าเว็บ                 เว็บเซิร์ฟเวอร์           ไฟห้อง แอร์ พัดลม ควัน โต๊ะ           ไฟโซน 3 + ไฟชั้น 9
                          รายการหนังสือ             ADC MCP3208 (LDR, LM35)
                                                   LCD 16×2, 7-segment, buzzer
```

## โปรโตคอลสื่อสาร (UART 115200 8N1)

| ทิศทาง | เฟรม | ความหมาย |
|---|---|---|
| ESP → บอร์ด 1 | `A5 cmd arg ~(cmd^arg)` | cmd `00` ขอสถานะ, `01` โหมดไฟ (1 = Manual), `02` หาหนังสือ (arg = โซน<<4 \| ชั้น, 0 = ยกเลิก), `03` ไฟห้อง (เฉพาะ Manual), `04` พัดลม |
| บอร์ด 1 → ESP | `5A flags ac loc ~(flags^ac^loc)` | ตอบทุกคำสั่งที่ถูกต้อง flags: bit0 ไฟห้อง, bit1 Manual, bit2 พัดลม, bit3 ควันอันตราย, bit4-6 โต๊ะ 1-3 / ac หน่วย 0.5 °C |
| บอร์ด 1 → บอร์ด 2 | `A5 loc ~loc` | ส่งซ้ำทุก 50 ms บอร์ด 2 ไม่ได้รับเกิน 500 ms จะดับไฟทั้งหมด |

โซนและชั้นใช้เลขเดียวกัน: **1 = แดง, 2 = น้ำเงิน, 3 = เขียว** หนังสือ Book No.1–9 วางไว้ครบทุกชั้นของทุกโซน
(Book No.1–3 อยู่โซน 1 ชั้นแดง/น้ำเงิน/เขียว, No.4–6 อยู่โซน 2, No.7–9 อยู่โซน 3)

## อุปกรณ์

- บอร์ด FPGA EDGE Spartan-7 2 บอร์ด
- บนบอร์ด 1 ใช้: ESP8266, ADC MCP3208 (LDR ที่ CH6, LM35 ที่ CH7), LCD 16×2, 7-segment 4 หลัก, buzzer, ปุ่มกด 2 ปุ่ม, สวิตช์เลื่อน
- ภายนอก: โมดูลเซนเซอร์ควัน MQ-2, LED ขาว 1 ดวง (ไฟห้อง), พัดลม DC เล็ก **ต่อผ่านวงจรขับ** (ทรานซิสเตอร์/MOSFET/โมดูล เพราะขา FPGA จ่ายกระแสพอแค่ LED), LED 12 ดวงสำหรับไฟโซนและไฟชั้นบนบอร์ด 2, ตัวต้านทาน 330 Ω
- สายระหว่างบอร์ด: บอร์ด 1 J5 ขา C14 → บอร์ด 2 J5 ขา C14 **และต่อ GND ของ 2 บอร์ดเข้าด้วยกัน**

ขาและการต่อสายทั้งหมดอยู่ใน [docs/pins.md](docs/pins.md)

## วิธีติดตั้ง

### FPGA
1. สร้างโปรเจกต์ Vivado (หรือใช้ FPGA Builder ของวิชา) part `xc7s15ftgb196-1`
2. เพิ่ม `fpga/board1.vhd` top = `board1_top` / `fpga/board2.vhd` top = `board2_top`
3. กำหนดขาตาม [docs/pins.md](docs/pins.md) (LVCMOS33, clock 50 MHz ที่ H11)
4. jumper: ถอด J9 (7-segment), บอร์ด 1 ใส่ J6 ที่ Enable (buzzer) และ J11 ที่ Enable (ESP8266)

### ESP8266 (ผ่าน USB-UART ของบอร์ด 1)
1. Arduino IDE ติดตั้งบอร์ด ESP8266 เปิด `esp8266/smart_library/smart_library.ino`
2. บอร์ด 1 ต้องลงโปรแกรม FPGA แล้ว ตั้ง **SW8 = 1** (คอมคุยกับ ESP ตรง), ต่อ **GPIO0 ที่ J10 ลง GND**, ย้าย J11 Disable → Enable เพื่อเข้าโหมดอัปโหลด
3. Tools → Reset Method = **no dtr (aka ck)** แล้ว Upload
4. ถอด GPIO0 ออกจาก GND, ย้าย J11 Disable → Enable, ตั้ง **SW8 = 0**

### ใช้งาน
1. ต่อ Wi-Fi `SmartLibrary` แล้วเปิด `http://192.168.4.1`
2. แตะหน้าเว็บ 1 ครั้งหลังเปิด เพื่อให้ browser ยอมเล่นเสียงเตือน (บน Android ต้องเปิดระดับเสียงสื่อ/Media)
3. ทดสอบเสียงเตือนได้ที่ Environment → Smoke → Manage แล้วแตะกล่องสถานะ

## การตรวจสอบ

- VHDL ทั้ง 2 ไฟล์ผ่าน `ghdl -a --std=93c` (Vivado อ่านเป็น VHDL-93) และผ่าน testbench ใน GHDL:
  บอร์ด 1 ตรวจการตอบคำสั่ง, คำสั่งที่มาระหว่างกำลังส่ง, เฟรมไปบอร์ด 2, โหมดไฟ ปุ่ม พัดลม, โต๊ะบน LCD, ควันกับ buzzer
  บอร์ด 2 ตรวจครบ 9 ตำแหน่ง, เฟรมเสีย, ค่าเกินช่วง, หมดเวลา, ไฟบอกสถานะ, ตัวนับเฟรมเสีย
- หน้าเว็บตรวจด้วย Chrome ที่ความกว้าง 320, 390, 820, 1366 และ 1920 px

ผลที่ยืนยันบนบอร์ดจริงแล้ว:
- UART ระหว่างคอม, FPGA และ ESP8266 ใช้ได้ทั้งสองทาง (อัปโหลดโปรแกรม ESP ผ่านบอร์ดได้) ลูกศรทิศ UART ในคู่มือบอร์ดหน้า 6–7 กลับด้าน
- buzzer ดังเมื่อตรวจพบควันและเมื่อเปิด SW9
- เสียงเตือนบนมือถือ Android (Chrome) ดัง

ยังต้องตรวจบนบอร์ด: ค่าสเกลอุณหภูมิ LM35, เกณฑ์ความสว่างของ LDR, พัดลมผ่านวงจรขับ, ความเสถียรของสายระหว่างบอร์ด (ดูหัวข้อ "ตรวจการคุยกันระหว่างบอร์ด" ใน [docs/pins.md](docs/pins.md))

## สิ่งที่ต่างจาก Proposal

| Proposal | ชิ้นงานจริง |
|---|---|
| คอมต่อบอร์ด 1 ผ่าน USB-UART | ใช้ ESP8266 บนบอร์ด 1 เปิด Wi-Fi ให้มือถือและคอมเข้าเว็บได้ไม่ต้องต่อสาย |
| ไฟห้อง LED ขาว 3 ดวง | 1 ดวง |
| เว็บแสดงสถานะพัดลมอย่างเดียว | เว็บเปิด-ปิดพัดลมและไฟห้อง (Manual) ได้ด้วย |
| ไฟชั้นหนังสือ 9 ดวง สีแดง เหลือง เขียว | ไฟโซน 3 ดวง + ไฟชั้น 9 ดวง สีแดง น้ำเงิน เขียว |
