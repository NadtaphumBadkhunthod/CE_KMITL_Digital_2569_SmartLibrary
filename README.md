# Smart Library (ระบบห้องสมุดอัจฉริยะ)

โครงงานวิชา **01076113 Digital System Fundamentals in Practice** ภาคเรียนที่ 1/2569 คณะวิศวกรรมศาสตร์ สจล. (KMITL)

ระบบห้องสมุดจำลองที่ใช้บอร์ด FPGA **EDGE Spartan-7 (XC7S15-FTGB196) 2 บอร์ด** เป็นหน่วยประมวลผลหลัก
ตรรกะควบคุมทั้งหมดอยู่ใน FPGA ส่วน ESP8266 บนบอร์ด 1 ทำหน้าที่เป็นเว็บเซิร์ฟเวอร์และเก็บรายการหนังสือ
ผู้ใช้ค้นหาหนังสือผ่านคอมพิวเตอร์ของห้องสมุดที่เชื่อมต่อ Wi-Fi ของ ESP8266 ไว้แล้ว

- [Proposal_SmartLibrary_updated.pdf](Proposal_SmartLibrary_updated.pdf) ข้อเสนอโครงงานฉบับปรับปรุงตามชิ้นงานจริง ([ฉบับแรก](Proposal_SmartLibrary.pdf))

## ความสามารถ

| ระบบ | การทำงาน | อยู่ที่ |
|---|---|---|
| ไฟห้อง | LED ขาว 3 ดวงบนขาเดียว / Auto ตามความสว่างจาก LDR / Manual กดปุ่ม SW14 หรือเว็บ / สลับโหมดด้วยปุ่ม SW18 หรือเว็บ | บอร์ด 1 |
| แอร์ | จำลองบน 7-segment เช่น `24.5C` ปรับทีละ 0.5 °C ทุก 2 วินาทีตามอุณหภูมิห้องจาก LM35 ในช่วง 16–27 °C | บอร์ด 1 |
| พัดลม | เปิด-ปิดด้วยปุ่ม SW16 หรือเว็บ | บอร์ด 1 |
| เตือนควัน | MQ-2 อันตรายแล้ว buzzer ดังเป็นจังหวะ, LCD ขึ้น `!! FIRE ALARM !!`, เว็บแจ้งเตือนเต็มจอพร้อมไซเรน | บอร์ด 1 + เว็บ |
| ที่นั่ง | 7 ที่นั่ง สวิตช์ 3 ตัวเป็นเลขฐานสอง 0–7 = จำนวนที่มีคน แสดงบน LCD 16×2 และแถบที่นั่ง 1–7 บนเว็บ | บอร์ด 1 + เว็บ |
| หาหนังสือ | เว็บแสดงทุกเล่มแล้วกรองตามคำค้นหา กด Follow แล้ว buzzer เล่นเพลง บอร์ด 2 เปิดไฟโซนและไฟชั้น 7-segment แสดง `โซน-ชั้น` | เว็บ + บอร์ด 1 + บอร์ด 2 |

## โครงสร้างระบบ

```
คอมพิวเตอร์ห้องสมุด ──Wi-Fi──► ESP8266 (บนบอร์ด 1) ──UART──► FPGA บอร์ด 1 ──UART (J5 C14)──► FPGA บอร์ด 2
  หน้าเว็บ                    เว็บเซิร์ฟเวอร์            ไฟ แอร์ พัดลม ควัน ที่นั่ง เพลง      ไฟโซน 3 + ไฟชั้น 9
                             รายการหนังสือ              ADC MCP3208 (LDR, LM35)
                                                       LCD 16×2, 7-segment, buzzer
```

## โปรโตคอลสื่อสาร (UART 115200 8N1)

| ทิศทาง | เฟรม | ความหมาย |
|---|---|---|
| ESP → บอร์ด 1 | `A5 cmd arg ~(cmd^arg)` | cmd `00` ขอสถานะ, `01` โหมดไฟ (1 = Manual), `02` หาหนังสือ (arg = โซน<<4 \| ชั้น, 0 = ยกเลิก), `03` ไฟห้อง (Manual), `04` พัดลม |
| บอร์ด 1 → ESP | `5A flags ac loc ~(flags^ac^loc)` | flags: bit0 ไฟห้อง, bit1 Manual, bit2 พัดลม, bit3 ควันอันตราย, bit4-6 จำนวนที่นั่งที่มีคน 0–7 / ac หน่วย 0.5 °C |
| บอร์ด 1 → บอร์ด 2 | `A5 loc ~loc` | ส่งทุก 50 ms ไม่ได้รับเกิน 500 ms บอร์ด 2 ดับไฟทั้งหมด |

โซนและชั้นใช้เลขเดียวกัน: **1 = แดง, 2 = น้ำเงิน, 3 = เขียว** (ชั้นสีเขียวใช้ LED สีเหลืองเพื่อให้สว่างขึ้น ไฟโซนเขียวยังเป็น LED เขียว)

## อุปกรณ์

- บอร์ด FPGA EDGE Spartan-7 2 บอร์ด
- บนบอร์ด 1: ESP8266, ADC MCP3208 (LDR ที่ CH6, LM35 ที่ CH7), LCD 16×2, 7-segment, buzzer, ปุ่มกด 3 ปุ่ม, สวิตช์เลื่อน
- ภายนอก: MQ-2, LED ขาว 3 ดวง (ไฟห้อง), พัดลม DC **ต่อผ่านวงจรขับ**, LED ไฟโซน 3 ดวง + ไฟชั้น 9 ดวง, ตัวต้านทาน 220 Ω 15 ตัว
- สายระหว่างบอร์ด: บอร์ด 1 J5 ขา C14 → บอร์ด 2 J5 ขา C14 **และต่อ GND ของ 2 บอร์ดเข้าด้วยกัน**

## วิธีติดตั้ง

### FPGA
1. Build ด้วย Vivado (part `xc7s15ftgb196-1`) จาก `fpga_build/build_board1.tcl` และ `build_board2.tcl` หรือใช้ไฟล์ `.bit` ที่มีอยู่
2. รัน `upload_board1_prom.bat` / `upload_board2_prom.bat` แล้วกด SW1
3. jumper: ถอด J9, บอร์ด 1 ใส่ J6 ที่ Enable (buzzer) และ J11 ที่ Enable (ESP8266)

### ESP8266 (ผ่าน USB-UART ของบอร์ด 1)
1. Arduino IDE: Generic ESP8266 Module, Flash 4MB (FS:2MB), DIO, Reset Method = **no dtr (aka ck)**
2. ตั้ง **SW8 = 1**, ต่อ **GPIO0 ที่ J10 ลง GND**, ย้าย J11 Disable → Enable แล้ว Upload
3. ถอด GPIO0 ออกจาก GND, รีเซ็ต ESP ด้วย J11, ตั้ง **SW8 = 0**

### ใช้งาน
เชื่อมต่อ Wi-Fi `SmartLibrary` (รหัส `library123`, สูงสุด 8 เครื่อง) แล้วเปิด `http://192.168.4.1`
